# Runtime dependencies for the Vercel Python function (api/index.py).
#
# Derived from requirements.txt with the pieces a hosted, key-free deployment
# cannot use removed. Every omission is deliberate:
#
#   * celery[redis] / redis — the studio pipeline runs on ThreadPoolExecutor,
#     not Celery (verified: a full import renders 4 clips with Redis down).
#     Verified again here so a silent dependency cannot creep back:
#     `pytest backend/tests/test_vercel_runtime.py`.
#   * pytest / pytest-cov / pytest-mock — test tooling, not runtime; they are
#     ~15 MB of the 500 MB Python function budget.
#   * mcp — only used by `autoclip mcp`, a local/server-side entry point.
#
# ffmpeg-binaries is required: Vercel's Python runtime has no system ffmpeg, so
# both binaries (157 MB) ship inside the function. The whole bundle measures
# ~474 MB against Vercel's 500 MB Python limit. Do not add packages here
# without checking `du -sm` afterwards.
-r requirements.txt

# Build-time only: pull the static ffmpeg/ffprobe into the bundle.
ffmpeg-binaries==1.1.0

# Keep the bundle under the cap: drop the test tooling and the MCP server.
# pip has no "exclude", so these are removed during the build instead
# (see scripts/build-vercel.sh).
